Maya Maths Foundation 2.0.5g Supported Practice

Builds on the approved 3×–9× foundation.
Changes in this test build:
- 3× split facts now explicitly use groups in words and visuals.
- Decomposed multiplication uses bracketed component facts consistently.
- 3×6, 3×7 and 3×12 visuals match their grouping strategy.
- 3×7 Challenge explanation uses the same group/bracket model.
- Existing lesson selection, practice coverage, journal/statistics and navigation logic is unchanged.


2.0.5c: Lesson Setup factor buttons now open a factor with no facts preselected. Use Select All or choose individual facts explicitly.

2.0.5e: Challenge integrity fix. Targeted/mixed Challenge feedback now derives its visual from the exact selected fact, not the challenge list position. Full-table 7× and 9× challenge visuals were also corrected so multi-step word-problem visuals match the final answer.


2.0.5f: Restores approved word-problem difficulty progression for targeted and mixed lessons. Challenge now presents Guided Practice → Apply Your Thinking → Challenge Yourself while using only the exact saved selected-fact pool. Multi-step Challenge feedback explicitly shows the selected multiplication fact first and the additional step second.


2.0.5g: Discover & Learn now launches a distinct Supported Practice mode. In Supported Practice, Another Way to Think and teaching visuals are available before an answer attempt. Main Practice remains Independent Practice and keeps support locked until the first attempt. Supported attempts are stored separately from independent-recall statistics and do not advance independent Practice coverage.
