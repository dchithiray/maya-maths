# Maya Maths — Foundation Edition 0.92

A strategy-based mathematics learning experience built around the Secret of 9.

## Files

- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — learning interactions and activities

## Open locally

Double-click `index.html`, or right-click it and open it with Microsoft Edge or Google Chrome.

## Publish with GitHub Pages

Upload all four files to the root of the `maya-maths` repository, replacing older versions where necessary.
Then commit the changes. GitHub Pages should update automatically.
