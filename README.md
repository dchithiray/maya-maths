# Maya Maths

**Current Release:** **v1.6.1**

**Helping children understand mathematics, not just memorise it.**

Maya Maths is an educational project designed to help primary school
students build strong mathematical foundations through:

-   Visual learning
-   Multiple thinking strategies
-   Guided discovery
-   Deliberate practice
-   Parent and teacher support

The project is being developed alongside the learning journey of one
Grade 6 student (Maya), with continuous feedback from her tutor.

## Educational Philosophy

Maya Maths aims to help children become confident mathematical thinkers
by:

-   Building on what they already know.
-   Teaching only the genuinely new learning.
-   Encouraging more than one way to solve a problem.
-   Keeping cognitive load low.
-   Using stories, patterns, arrays and number relationships.
-   Celebrating understanding before speed.
